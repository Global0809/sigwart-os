SIGWART_OS // PHOTO DROP INSTRUCTIONS
=====================================

Drop photos into this folder (assets\photos\) using EXACTLY these base
names. Formats are tried in this order:  .webp -> .jpg -> .jpeg -> .png
(so "portrait.jpg" and "portrait.webp" both work).

After replacing a photo, hard-refresh the browser (Ctrl+F5).

  portrait.*   the operator portrait
               -> B00 GATE hero frame (head/eye cursor-follow)
               ideal: 4:5 ratio, ~1200 x 1500 px
               framing: face centered, EYES IN THE UPPER THIRD
               (the eye-tracking band sits ~26% from the top)

  archive.*    poster / artwork
               -> B01 OPERATOR archive card (tilt / hover)
               ideal: 4:5 ratio, ~1000 x 1250 px

  vehicle.*    the wide cinematic shot
               -> B02 VEHICLE BAY panorama (parallax + x-ray overlay)
               ideal: 16:9 to 21:9, at least ~1800 px wide
               framing: keep the subject HORIZONTALLY CENTERED -
               desktop shows an ultra-wide slice, phones crop the
               sides to roughly 4:5

Notes
-----
- Exact ratios are optional: every slot cover-crops gracefully.
- Missing/misnamed files never break the site - a holographic
  "NO VISUAL FEED" fallback appears instead.
- Keep files under ~400 KB each for fast mobile loading.
- Your original uploads are preserved in assets\photos\originals\
